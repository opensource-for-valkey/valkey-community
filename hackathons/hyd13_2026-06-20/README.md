# Valkey Hackathon — Hyderabad 2026

![valkey-logo](https://valkey.io/img/valkey-horizontal.svg)

**Build real open source contributions for Valkey.**

📅 June 20–21, 2026
📍 Amazon HYD13 Office, Hyderabad, India

---

## Overview

This is a 2-day in-person hackathon where participants build end-to-end applications or integrations with major frameworks, libraries, and projects — all contributing back to the Valkey open source ecosystem.

Valkey is a high-performance key/value datastore backed by the Linux Foundation, supporting caching, message queues, and primary database workloads.

## Format

| Day | Date | Activity |
|-----|------|----------|
| Day 1 | Saturday, June 20 | Hackathon kickoff — teams form, pick projects, and start coding |
| Day 2 | Sunday, June 21 | In-person at Amazon HYD13 — mentorship, guidance, and project presentations |

## How It Works

1. **Form a team** — Teams of 2 to 4 participants.
2. **Pick a project** — Choose from the [proposed integrations/applications](./Valkey-Hackathon.md) or propose your own novel use case for Valkey.
3. **Build it** — Create a complete, end-to-end application or integration with a real open source project.
4. **Submit a PR** — All work is done on GitHub as real open source contributions.
5. **Present** — Demo your project on Day 2 at the HYD13 office.

## Timeline

```
June 20 (Sat)    Hackathon starts — remote kick-off, team formation, coding begins
June 21 (Sun)    In-person day at Amazon HYD13 — mentorship, office hours, presentations
June 22 – Jul 5  Grace period — 2 extra weeks to work with open source maintainers to get PRs merged
```

## Prizes & Rewards

| Tier | Who | Reward |
|------|-----|--------|
| 🎁 Participation | All participants | Gift kit |
| 🏆 Challenge Complete | Teams that complete the challenge | Digital credits prize |
| 🌟 Merged & Accepted | Teams whose integration is merged upstream | Highlighted in Valkey community channels |

## Winning Criteria

- **Complete the challenge**: Deliver a working end-to-end integration or application submitted as a GitHub PR to the target project.
- **Get merged**: If your PR is accepted by the upstream open source maintainers (within the 2-week grace period), your team earns additional recognition and will be featured across Valkey community channels.

## Rules

- All work must be done during the hackathon period (June 20 – July 5 including grace period).
- Teams must consist of 2 to 4 members.
- Projects must be real contributions to open source — submitted as GitHub pull requests.
- Teams choose from the [proposed projects/applications](./Valkey-Hackathon.md) or propose an alternative integration/application using Valkey.
- Code must be original work created during the hackathon.
